Version 2026.2.1

New Features

  • Top file support — full validation and code completion for top.sls files: environment structure validation, matcher key diagnostics, and SLS path resolution.
  • Matcher validation — 13 matcher types are now validated in top.sls: glob, pcre, grain, grain_pcre, pillar, pillar_exact, compound, ipcidr, list, nodegroup, range, data, and explicit match: <type> declarations.
  • Top file completion — code completion for environments, matcher types, and SLS entry paths (dot-notation) based on configured file and pillar roots.
  • Quick Documentation for top files — Ctrl+Q now provides context-sensitive documentation for environments and matcher keys in top.sls.
  • SLS path validation — dot-notation SLS paths are validated against the project file tree; Jinja expressions in paths are recognized and skipped.
  • Pillar root support — completions and validation in pillar top.sls files now resolve paths against configured pillar roots.
  • What's New notifications — in-IDE notifications about plugin updates with an embedded "What's New" tab.
  • File type conflict handling — improved detection and resolution of .sls file type conflicts with other plugins.
  • IntelliJ Platform 2026.2 support — compatible with build 262.*.

Bug Fixes

  • Fixed SLS completion for quoted YAML entries.
  • Fixed init.sls files being shown as raw paths instead of parent state names in completion results.
  • Top files (top.sls) are no longer suggested as SLS entries in completions.

Version 2026.2.0

New Features

  • Enhanced Jinja highlighting in Salt files — YAML syntax highlighting now works correctly across embedded Jinja fragments, preserving proper colors and code insight for both YAML and Jinja regions.
  • Automatic Jinja2 support for .sls files — the .sls extension is now automatically registered for Jinja2 support when a project is opened, eliminating the need for manual configuration.
  • IntelliJ Platform 2026.2 support — compatible with build 262.*.

Improvements

  • Improved error reporting with better crash diagnostics.
